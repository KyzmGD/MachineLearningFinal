# Dataset

Dự án sử dụng CSE-CIC-IDS2018.

Nguồn chính thức:

https://www.unb.ca/cic/datasets/ids-2018.html

## Cách chuẩn bị

1. Tải phiên bản CSV.
2. Giải nén dataset.
3. Đưa các file CSV vào Google Drive:

MyDrive/CICIDS2018/

4. Trong notebook, cấu hình:

DRIVE_DATA_DIR = "/content/drive/MyDrive/CICIDS2018"

## Lưu ý

Dataset không được lưu trong GitHub vì dung lượng lớn.
Notebook tự động tìm các file CSV trong thư mục con.
